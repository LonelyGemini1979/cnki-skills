# 使用说明

## 快速开始

安装完成后，直接对Hermes说出你的需求即可。

## 功能示例

### 1. 基础检索

**场景**: 搜索某个主题的论文

**示例对话:**
```
你: 帮我搜索"颈椎病"相关的中文论文
Hermes: 我将使用CNKI检索"颈椎病"相关文献...
[自动打开知网，输入关键词，获取结果]

你: 搜索"人工智能在医学影像中的应用"
Hermes: [执行搜索并返回结果列表]
```

**返回结果:**
- 论文标题
- 作者列表
- 期刊名称
- 发表日期
- 下载链接

### 2. 高级检索

**场景**: 需要精确筛选条件

**示例对话:**
```
你: 搜索2020-2024年张三发表的颈椎病论文，限北大核心期刊
Hermes: [使用高级检索，设置作者、时间、期刊级别筛选]

你: 查找《中华骨科杂志》上关于MRI的论文
Hermes: [设置期刊名称和关键词筛选]
```

**支持筛选:**
- 作者
- 标题
- 期刊名称
- 发表时间范围
- 来源类别（SCI/EI/CSSCI/北大核心）
- 文献类型（期刊/博硕/会议）

### 3. 下载文献

**场景**: 获取论文全文

**示例对话:**
```
你: 下载这篇论文的PDF
Hermes: [点击PDF下载链接，保存文件]

你: 下载CAJ格式
Hermes: [点击CAJ下载链接]
```

**注意事项:**
- 需要知网账号登录
- 部分论文需要付费或机构权限
- 可能遇到验证码，需手动完成

### 4. 导出引用

**场景**: 保存到文献管理工具

**示例对话:**
```
你: 将这篇论文导出到Zotero
Hermes: [提取引用信息，推送到Zotero]

你: 保存为RIS格式
Hermes: [生成RIS文件并保存]
```

**支持格式:**
- Zotero直接推送
- RIS文件
- GB/T 7714格式

### 5. 期刊查询

**场景**: 查询期刊信息

**示例对话:**
```
你: 《中华骨科杂志》是北大核心吗？
Hermes: [查询期刊收录情况，返回结果]

你: 这个期刊的影响因子是多少？
Hermes: [提取影响因子数据]
```

**返回信息:**
- 收录数据库（北大核心、CSSCI、CSCD、SCI、EI等）
- 影响因子
- 期刊级别
- 主办单位

### 6. 论文详情

**场景**: 获取论文完整信息

**示例对话:**
```
你: 获取这篇论文的详细信息
Hermes: [打开详情页，提取完整信息]
```

**返回信息:**
- 标题、作者、机构
- 摘要、关键词
- 基金项目
- 分类号
- DOI
- 参考文献
- 引证文献

## 常见问题

### Q: 遇到验证码怎么办？
A: 知网使用腾讯滑块验证码，需要手动完成。Hermes会暂停并提示你操作。

### Q: 下载失败怎么办？
A: 检查是否已登录知网账号，或该论文是否需要付费。

### Q: 搜索结果为空？
A: 尝试更换关键词，或使用高级检索扩大范围。

### Q: 如何批量下载？
A: 目前支持单篇下载，可以连续操作多篇。

### Q: 支持哪些文献管理工具？
A: 目前支持Zotero，其他工具可以通过RIS格式导入。

## 最佳实践

1. **精确关键词**: 使用专业术语，避免过于宽泛
2. **合理筛选**: 使用高级检索缩小范围
3. **控制频率**: 每次操作间隔3-5秒
4. **保存结果**: 及时导出或下载重要文献
5. **处理验证码**: 遇到验证码时耐心手动完成

## 限制说明

- 不支持绕过知网付费墙
- 不支持自动破解验证码
- 下载速度受知网服务器限制
- 部分功能需要知网账号权限
