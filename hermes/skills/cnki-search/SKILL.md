# 中国知网(CNKI)文献检索工具

通过浏览器自动化访问中国知网，检索和下载中文学术文献。

## 功能特性

- **文献检索**: 关键词搜索、高级检索（多字段组合）
- **结果解析**: 提取论文标题、作者、期刊、摘要、下载链接
- **论文详情**: 获取完整论文信息、参考文献、引证文献
- **文献下载**: 下载PDF/CAJ格式全文（需知网账号）
- **期刊检索**: 按期刊名称检索、期刊导航
- **数据导出**: 导出检索结果到CSV/JSON

## 使用前准备

### 1. 启动浏览器

CNKI skill使用Hermes的浏览器工具。确保浏览器已启动：

```bash
# 启动camofox浏览器（如果未运行）
hermes browser start
```

### 2. 登录知网（可选）

如需下载全文，需要先在浏览器中登录知网账号：
- 打开 https://www.cnki.net
- 点击"登录"并输入账号密码
- 登录状态会在浏览器会话中保持

## 使用方法

### 基础检索

```
用户: 帮我搜索"颈椎病"相关的中文论文
助手: 我将使用CNKI检索"颈椎病"相关文献...
```

### 高级检索

支持多字段组合检索：
- 主题词检索
- 作者检索
- 期刊名称检索
- 发表时间范围
- 文献类型筛选（期刊、博硕、会议）

### 获取论文详情

```
用户: 获取这篇论文的详细信息
助手: 我将打开论文详情页，提取完整信息...
```

### 下载全文

```
用户: 下载这篇论文的PDF
助手: 我将尝试下载PDF全文...
```

## 工作流程

1. **打开知网**: 导航到 https://kns.cnki.net/kns8s/defaultresult/index
2. **输入关键词**: 在搜索框输入检索词
3. **执行搜索**: 点击搜索按钮
4. **解析结果**: 提取论文列表信息
5. **获取详情**: 点击论文标题进入详情页
6. **下载全文**: 点击PDF/CAJ下载链接

## 注意事项

### 反爬虫机制

知网有反爬虫机制，可能会遇到：
- **腾讯滑块验证码**: 需要手动完成验证
- **访问频率限制**: 建议每次搜索间隔3-5秒
- **IP限制**: 频繁访问可能导致临时封禁

### 下载权限

- **免费论文**: 部分论文可直接下载
- **付费论文**: 需要知网账号或机构订阅
- **CAJ格式**: 部分论文仅提供CAJ格式，需要CAJViewer打开

### 浏览器要求

- 使用Chrome/Firefox浏览器
- 启用JavaScript
- 允许弹出窗口（下载时）

## 技术实现

CNKI skill通过Hermes的浏览器工具实现：
- `browser_navigate`: 打开网页
- `browser_snapshot`: 获取页面结构
- `browser_type`: 输入文本
- `browser_click`: 点击元素
- `browser_console`: 执行JavaScript提取数据

## 常见问题

### Q: 遇到验证码怎么办？
A: 知网使用腾讯滑块验证码，需要手动完成。脚本会暂停并提示用户操作。

### Q: 下载失败怎么办？
A: 检查是否已登录知网账号，或该论文是否需要付费。

### Q: 搜索结果为空？
A: 尝试更换关键词，或使用高级检索扩大范围。

### Q: 如何批量下载？
A: 目前支持单篇下载，批量下载需要逐篇操作。

## 限制说明

- 不支持绕过知网付费墙
- 不支持自动破解验证码
- 下载速度受知网服务器限制
- 部分功能需要知网账号权限
